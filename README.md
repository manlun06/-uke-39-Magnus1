## Mine refleksjoner

### Hva har du lært om Git og GitHub?

Jeg har lært at Git brukes til å holde oversikt over endringer i et prosjekt. GitHub brukes til å lagre prosjekter på nettet. Jeg har også lært om repository, commits og hvordan man kan laste opp endringer til GitHub.

### Hva synes du om å bruke versjonskontroll?

Jeg synes versjonskontroll er nyttig fordi man kan se hvilke endringer som har blitt gjort. Det gjør det også lettere å gå tilbake til en tidligere versjon hvis noe går galt.

### Hva har du lært om Markdown?

Jeg har lært hvordan Markdown kan brukes til å formatere tekst på en enkel måte. Jeg har blant annet lært å lage overskrifter, lister, lenker, bilder, tabeller og kodeblokker.

### Hvordan kan Markdown brukes til dokumentasjon?

Markdown kan brukes til å dokumentere prosjekter. En README-fil kan for eksempel forklare hva prosjektet gjør, hvilke programmeringsspråk som brukes og hvordan prosjektet kan kjøres.

### Hva var mest utfordrende?

Det mest utfordrende var å huske riktig Markdown-syntaks og lære hvordan Git og GitHub fungerer sammen. Etter å ha prøvd flere ganger ble det lettere å bruke det.
